# Visão Estratégica

O PdfExpert v8 será uma plataforma híbrida:

* Execução LOCAL ultra otimizada
* Plataforma SaaS escalável
* Compatível com Replit usando baixo consumo de créditos
* Deploy automatizado no GitHub
* Pipeline inteligente para processamento massivo de PDFs
* Extração avançada de imagens em alta resolução
* IA para correção automática de nomes dos produtos
* Sistema resiliente com logs, fallback e recuperação automática

O objetivo NÃO é apenas extrair imagens.

O objetivo é criar:

> Uma plataforma profissional de automação comercial para transformar catálogos PDF em bancos estruturados de produtos prontos para ecommerce, marketplaces e ERPs.

---

# Objetivos Principais

## O sistema deve:

### 1. Processar PDFs automaticamente

* PDFs únicos
* Múltiplos PDFs simultaneamente
* Pastas inteiras
* Catálogos pesados
* PDFs escaneados
* PDFs híbridos

---

### 2. Extrair imagens em qualidade máxima

O sistema deve:

* Extrair imagens originais sem compressão
* Preservar resolução nativa
* Priorizar imagens acima de 4K
* Melhorar nitidez automaticamente
* Corrigir ruído
* Remover fundo opcionalmente
* Detectar imagens duplicadas
* Reorganizar imagens por produto

---

### 3. Detectar nome correto do produto

A IA deve:

* Ler títulos
* Corrigir OCR
* Remover códigos inúteis
* Identificar SKU
* Detectar marca
* Padronizar nomes
* Gerar slug SEO
* Criar nome comercial limpo

Exemplo:

```txt
Entrada:
REF 8472-X CAB MDF PREM BR 2P

Saída:
Armário MDF Premium Branco 2 Portas
```

---

### 4. Criar estrutura pronta para ecommerce

O sistema deve gerar:

```txt

            imagem2.png
            data.json
```

---

### 5. Deploy automático GitHub

Toda execução SaaS deve:

* Fazer commit automático
* Organizar branch
* Versionar processamento
* Gerar changelog
* Subir resultados automaticamente

# Estratégia de Baixo Consumo

## Regras obrigatórias

### 1. Processamento sob demanda

Nada roda continuamente.

Tudo funciona por:

* fila
* eventos
* tarefas assíncronas

---

### 2. Zero IA pesada local

NÃO usar:

* LLM gigantes
* modelos pesados
* GPU obrigatória

USAR:

* OCR leve
* regex inteligente
* heurística otimizada
* cache agressivo

---

### 3. Pipeline modular

Cada módulo executa separadamente:

```txt
PDF → OCR → Imagem → Nome → Exportação
```

Isso evita:

* travamentos
* consumo contínuo
* estouro de memória

---

### 4. Cache inteligente

Salvar:

* OCR já processado
* hashes das imagens
* nomes já corrigidos
* PDFs já convertidos

Evita retrabalho.

---

### 5. Processamento incremental

Ao alterar apenas 1 PDF:

* processar somente ele
* não reconstruir tudo

# Exemplo de BAT Profissional

```bat
@echo off
title PdfExpert v8
color 0A

:START
cls

echo ======================================
echo        PDFEXPERT V8 STARTING
echo ======================================

echo.
echo Verificando ambiente...

python --version

if errorlevel 1 (
    echo Python nao encontrado.
    pause
    goto END
)

echo.
echo Iniciando sistema...

echo Logs em:
echo logs\runtime.log

echo.

python main.py >> logs\runtime.log 2>&1

if errorlevel 1 (
    echo.
    echo ERRO DETECTADO
    echo Verifique logs\runtime.log
    echo.
    pause
    goto START
)

:END
pause
```
